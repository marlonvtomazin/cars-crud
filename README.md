# 🚗 Car CRUD API

A RESTful API built with **Java** and **Spring Boot** for managing cars.  
This project demonstrates clean architecture, REST best practices, and basic CRUD operations.

---

## 📌 Features

- Create a new car
- Retrieve a car by ID
- Retrieve all cars
- Partially update a car (PATCH)
- Delete a car
- Transaction management with Spring Data JPA

---

## 🛠️ Technologies Used

- Java 25
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- Lombok
- H2 / PostgreSQL (configurable)
- Maven
